##Sobre o Projeto
**Real ou IA: O desafio da percepção** é um Quiz Educacional desenvolvido como avaliação (A3) para a faculdade.
**Justificativa:** Hoje em dia, principalmente nas redes sociais, está se espalhando muita mídia gerada por Inteligência Artificial. Empresas utilizam ferramentas de IA para melhorar seu alcance e entregar mais conteúdo, mas essas mesmas ferramentas também são frequentemente usadas para criar "fake news" e cenários inexistentes. Com as melhorias contínuas dessas tecnologias, se o usuário não se atentar, pode facilmente acabar acreditando em um vídeo ou imagem falsa. Este projeto visa conscientizar e treinar o olhar dos usuários para identificar essas mídias.

##Funcionalidades Principais
O Quiz terá 3 pilares principais:
1.  **Modo de Comparação:** O quiz irá exibir mídias (vídeos ou fotos) que serão consumidas de forma dinâmica através de um arquivo `JSON`.
2.  **Sistema Educativo:** Após a resposta do usuário, o quiz liberará um feedback imediato (positivo ou negativo) acompanhado de um aviso educacional explicando os detalhes da imagem/vídeo.
3.  **Sistema de Pontuação:** Conforme o usuário avança nas questões, o sistema irá calcular e atualizar a pontuação (de forma positiva ou negativa) com base nos acertos e erros.
